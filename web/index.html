mpftp — In-editor serial REPL, FTP & flasher extension.

mpftp is an in-editor workbench extension for VS Code and compatible derivatives (such as Google Antigravity IDE, Cursor, VSCodium). It provides a dual-pane file transfer interface, integrated serial REPL console, and automated firmware flashing utilities for MicroPython and CircuitPython boards across Linux, Windows, and WSL.

Workbench Utilities & Features

Dual-Pane FTP Explorer

Drag-and-drop file transfer, folder sync, auto pre-compilation of .py to .mpy bytecode before transfer.

In-Editor Serial REPL

Full VT100 terminal emulation with tab completion, Ctrl+C interrupt, Ctrl+D soft reset, and baud rate selection.

Automated Firmware Flasher

One-click firmware flashing utility supporting esptool (ESP32), picotool (RP2040/RP2350), and uf2mounts.

MIP & CircUp Helpers

Integrated package manager helpers for installing dependencies directly from the PyDevices MIP index onto connected MCUs.
